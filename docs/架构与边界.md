# 架构与边界

## 数据流

```text
中文指令
  → parse_compound_instruction()
  → [绿色球，旁边，红色球] + [红色球，原位置，绿色球]
  → capture_scene_memory(): 保存绿色球初始 RGB 几何位置
  → BallVisionTracker: 红/绿颜色分割和相机坐标转换
  → execute_visual_place(): 接近、抓取、抬升、移动、放置
  → 视觉验证目标误差；受限纠偏或报告失败
```

## 已验证的内容

- MuJoCo / robosuite Panda 仿真中的双色小球任务；
- 中文复合指令的受约束解析与顺序执行；
- 只以 RGB 颜色视觉定位球，而非直接读取物体真值坐标；
- 初始位置记忆、视觉复核和结构化 JSON 结果；
- 成功回放中两步放置均已完成，误差为 0.61 cm 和 1.906 cm。

## 不应夸大的内容

- 颜色分割只适用于已知的红/绿目标和当前受控视觉条件，不是开放词表目标检测；
- 技能执行器是工程规则/教师控制器，不是端到端 VLA 控制策略；
- 检查点和示教数据用于颜色抓取行为克隆实验，不能代表完整复合放置任务由网络端到端完成；
- MuJoCo 成功不等于真实机械臂接触、相机噪声、抓取摩擦或现实环境泛化已验证。
